# UD1 · Introducción a PHP — Prácticas

Este directorio contiene los **siete enunciados y archivos de partida** para desarrollar las prácticas. Los programas PHP incluyen tareas pendientes por completar: al principio no mostrarán el resultado final.

## Puesta en marcha
1. Instala XAMPP y enciende **Apache**. No es necesario iniciar MariaDB para estas siete prácticas.
2. Copia las siete carpetas numeradas en `htdocs/UD1/` (por ejemplo, `C:\xampp\htdocs\UD1\`). Si instalaste XAMPP en otra ubicación, utiliza su carpeta `htdocs`.
3. Abre el archivo `ENUNCIADO.md` de cada práctica y completa los archivos `.php` y `.html` suministrados.
4. Accede desde el navegador mediante `http://localhost/UD1/NOMBRE_DE_CARPETA/ARCHIVO_DE_ENTRADA`. No ejecutes los `.php` con doble clic. Para la práctica 02, abre directamente `EJ1.php` a través de `localhost`.
5. Puedes editar y probar los archivos con tu editor de código preferido, guardarlos y recargar el navegador.
